# Primeira-aplicação-React-Native

My very first React Native mobile application — a learning project created while starting out with mobile development.

## Objective

The objective of this project is to explore the fundamentals of React Native by building a simple app, understanding the project structure, native components, and how to run a React Native application on Android and iOS simulators.

## Tech Stack

- React Native (Expo)
- JavaScript

## Getting Started

```bash
cd AwesomeProject
npm install
npx expo start
```
